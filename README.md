# E-book Hub

Redesenhe meu site “Mundo dos E-books” como uma loja moderna, profissional e responsiva de produtos digitais.

Use fundo azul-escuro quase preto, cards em tom mais claro, textos brancos e botões verdes. Crie um menu no topo com Início, E-books e Contato.

Na primeira seção, adicione o título “Transforme Conhecimento em Resultado”, uma descrição curta e um botão “Ver nossos e-books”.

Crie uma seção de produtos em formato de cards. Cada card deve ter capa do e-book, nome, descrição curta, preço e botão “Comprar agora”. O botão do e-book “Criação de Vídeos com Inteligência Artificial” deve abrir:

https://pay.kiwify.com.br/l754efr

Adicione uma seção com três benefícios: conteúdo prático, acesso imediato e aprendizado no seu ritmo.

No final, adicione contato, Instagram, TikTok e Telegram. Não mostre meu telefone diretamente; use apenas um botão para contato.

Deixe o site totalmente responsivo para celular, tablet e computador. Use HTML semântico, textos fáceis de ler, bom contraste, imagens com texto alternativo, botões grandes e foco visível para navegação pelo teclado. Corrija todas as tags HTML fora de ordem ou repetidas.
